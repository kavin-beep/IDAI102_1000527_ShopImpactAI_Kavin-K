# Usability feedback template

Five genuine, dated informal feedback responses are recorded in the README. This reusable template supports more detailed task-based feedback; automated checks and informal comments do not replace observed usability testing. Use participant aliases rather than unnecessary personal information.

## Tasks

Create an account and sign in again; add a purchase; find a monthly total; edit a mistake; compare choices; save preferences; export a backup; sign out and return to saved purchases. Ask the participant what the estimate does and does not measure.
